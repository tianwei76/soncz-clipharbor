# Soncz ClipHarbor

面向多平台短视频下载的 Chrome / Edge Manifest V3 扩展。目前仅实现抖音视频检测与下载，快手、TikTok 等平台尚未支持。无需登录扩展账号，也不依赖业务后端。

项目地址：https://github.com/tianwei76/soncz-clipharbor

## 安装与使用

1. 打开 `chrome://extensions/` 或 `edge://extensions/`，启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本目录。已安装旧版时，重新加载扩展并刷新抖音页面。
3. 打开 `https://www.douyin.com/video/视频ID`，播放视频。
4. 点击扩展图标，检测到视频后点击“下载视频”，选择保存位置。

插件默认建议文件名为 `douyin-videos/视频ID-标题.mp4`。实际下载进度和失败原因请查看浏览器下载列表。

## 支持范围

- 读取抖音网页已有的视频接口响应及当前可见播放器的 HTTP(S) 或 `blob:` 视频地址。
- 优先使用不含明显水印标记的播放地址；实际画质和水印取决于页面提供的资源。
- 视频以当前详情页 ID 匹配，标签页之间独立缓存，导航或关闭标签页时清理缓存。
- 页面只提供 `blob:` 地址时，会尝试由当前页面触发下载；如果该地址对应 MediaSource 媒体流，则不能直接作为完整视频文件下载，当前尚未实现媒体流合并。
- 无需插件账号；页面本身是否能访问视频仍由抖音决定。

升级到此版本会清理旧扩展的本地缓存，包括旧登录信息、采集记录及任务日志。

## 当前状态

当前版本处于开发阶段。已进行 JavaScript 语法检查、模拟播放器检测和消息传递验证，尚未完成真实抖音页面的完整下载验证。下载动作被触发不代表文件已成功保存，请以浏览器下载列表和实际文件为准。

## 项目文件与权限

- `manifest.json`：扩展元数据和权限，仅匹配抖音站点。
- `injected.js`：在页面中读取视频响应和可见播放器。
- `content.js`：向扩展转发当前页面的视频数据。
- `background.js`：浏览器扩展自身的后台脚本，按标签页管理本地缓存，不是服务端。
- `popup.html` / `popup.css` / `popup.js`：检测状态与下载操作。
- `icons/`：扩展图标。

权限为 `downloads`（创建视频下载）、`storage`（本地视频缓存）、`tabs`（读取当前页面并清理导航缓存）。无业务 API、远程登录或任务提交。

## 打包

在 PowerShell 中运行：

```powershell
./package-extension.ps1
```

产物：`dist/douyin-video-downloader-1.0.0.zip`。打包清单仅包含扩展运行所需文件。
